# Участие в разработке

Спасибо за желание улучшить VideoDownloader. Перед крупным изменением создайте
issue и опишите пользовательскую проблему, чтобы не дублировать работу.

## Локальная проверка

Используйте Python 3.12 и установите development-зависимости по README. Перед
pull request выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\check.ps1
```

Изменение поведения должно сопровождаться unit-тестами. Сетевые тесты и тесты с
реальными бинарниками помечайте `integration`, делайте opt-in и не используйте
чужой защищённый контент.

## Правила изменений

- сохраняйте разделение UI, моделей, сервисов и внешних процессов;
- не формируйте shell-команды из пользовательских данных;
- не добавляйте обход DRM, платных ограничений или защит сайтов;
- не коммитьте yt-dlp/FFmpeg, сборочные артефакты, cookies, URL из журналов,
  секреты и локальные настройки;
- для новых загружаемых файлов документируйте официальный источник, версию,
  архитектуру, лицензию и SHA-256;
- публичные классы и нетривиальные функции документируйте, а комментариями
  объясняйте причину решения;
- обновляйте `THIRD_PARTY_NOTICES.md`, если меняется состав дистрибутива.

Предпочтительны небольшие смысловые commits в повелительном английском стиле,
например `feat: add subtitle selection` или `fix: preserve tool on update
failure`. Не переписывайте чужую историю и не добавляйте сгенерированные
бинарники.
