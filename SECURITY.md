# Security policy

## Supported versions

Until the first public release, only the current `main` branch is maintained.
After version 1.0, this table should be replaced with the supported release
lines and their end-of-support dates.

## Reporting a vulnerability

After the repository is published, use GitHub Private Vulnerability Reporting.
Please include the affected version, Windows version, impact and minimal
reproduction steps. Do not publish working exploits, private media URLs,
authentication cookies or unredacted logs in a public issue.

There is currently no project email or external security inbox. This document
must be updated before publication if private reporting is not enabled.
