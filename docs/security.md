# Модель безопасности

## Границы доверия

- URL и метаданные сайта считаются недоверенными данными.
- Программа не создаёт shell-строку и не использует `shell=True`; URL передаётся
  `yt-dlp.exe` отдельным аргументом после `--`.
- Имена файлов формирует yt-dlp с `--windows-filenames` и ограничением длины.
- Внешние инструменты разрешены только из manifest/официального GitHub release,
  скачиваются во временный файл и принимаются после сверки SHA-256.
- Замена инструмента атомарна; до проверки новой версии сохраняется рабочий
  файл, позволяющий выполнить откат.

## Локальные данные

Настройки, журнал, архив загрузок и внешние инструменты лежат в пользовательских
каталогах. Программа не меняет `PATH`, не просит административных прав, не
устанавливает службы и не принимает входящие сетевые соединения. URL в журнале
маскируются; секреты, cookies и встроенный браузер авторизации версия 0.1.0 не
поддерживает.

## Сеть

Соединения инициируются только для анализа/загрузки выбранного URL и для
получения инструментов/проверки обновления. Само приложение не отправляет
телеметрию. HTTPS и контрольная сумма защищают доставку закреплённых бинарников,
но не заменяют подпись издателя. Windows installer версии 0.1.0 также не имеет
цифровой подписи и поэтому может вызвать предупреждение SmartScreen.

## Сообщение об уязвимости

До публикации GitHub-репозитория не существует приватного канала проекта.
После публикации следует включить GitHub Private Vulnerability Reporting и
обновить [SECURITY.md](../SECURITY.md). Не прикладывайте к публичному issue
рабочие эксплойты, персональные URL, cookies или журналы с чувствительными
данными.
