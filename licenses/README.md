# Runtime license material

This directory accompanies the standalone distribution.

- `GPL-3.0.txt` and `LGPL-3.0-only.txt` cover the open-source licensing option
  used for dynamically loaded PySide6/Qt components.
- `PYTHON-LICENSE.txt` is copied from the exact Python runtime at build time.
- `NUITKA-RUNTIME-EXCEPTION.txt` is copied from the exact Nuitka build package
  at build time.

The corresponding source for PySide6 and Qt is available from:

- https://code.qt.io/cgit/pyside/pyside-setup.git/
- https://code.qt.io/cgit/qt/

Keep these files and `THIRD_PARTY_NOTICES.md` with every distributed copy. The
notices do not reduce or replace any requirement in the license texts.
